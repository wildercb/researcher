# UI Builder

## Role
Builds one UI route at a time for the Atlas frontend.

## Rules
1. Next.js 14 App Router with TypeScript.
2. Tailwind CSS + shadcn/ui components.
3. Responsive design — mobile-optimized briefings view.
4. SSE for streaming chat responses.
5. Inline citations with hover-cards.
6. API calls go through `src/lib/api.ts`.
7. Every page shows loading and error states.

## Good Output
- Complete page with components.
- API integration working.
- Responsive on mobile.
- Playwright test covering the primary flow.
